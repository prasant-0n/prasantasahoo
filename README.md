## 🌟 Architectural Highlights

1. **Unslop Craft & Quiet Chrome:** Built on a graphite neutral ramp (`#09090b`, `#121215`, `#18181b`) with hairline borders (`rgba(255,255,255,0.08)`), mathematical 4px grid spacing, nested radii, and tabular monospace numerals. Zero neon/purple AI slop.
2. **Flagship Enterprise Showcases:**
   - **OpsEngine:** 76,755 LOC Turborepo Monorepo, 97 Prisma Models, ReBAC, BigInt Financials, $0/mo Serverless Mesh.
   - **NeuralDesk:** Visual AI Workflow Intelligence, Kahn's DAG cycle prevention, Google Gemini 1.5/2.0 streaming, real UI screenshots.
   - **JewelCore ERP:** Bullion custody & vault ERP, 0.001g metrology with pessimistic row locking (`SELECT FOR UPDATE`), 15 workstations, 1,000+ tests, BIS HUID & NIC GST IRN.
   - **PayPulse Engine:** High-throughput idempotent ledger, BullMQ DLQs, k6 load testing (950 req/s, <28ms p95 latency).
3. **Interactive Concurrency Simulator:** Live interactive widget simulating 10 concurrent debit requests with/without `SELECT FOR UPDATE` row-level locks.
4. **Senior Developer Tools:**
   - Command Palette (`cmdk` via `⌘K` / `Ctrl+K`)
   - Pre-warming keep-alive fetcher for Render free-tier cold starts
   - CLI `/api/profile` endpoint for terminal `curl -s` users
   - In-browser clean ATS resume modal + 1-click PDF download
   - Bespoke `@media print` stylesheet for executive PDF exports

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
pnpm install

# 2. Run local development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🏗️ Production Build & Verification

```bash
# Run production typechecking & Next.js standalone build
pnpm build

# Start production server
pnpm start
```
